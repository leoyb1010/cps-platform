## 二之二、第三轮整改（压测 + 对抗审计，2026-08-08）

| 级别 | 报告发现 | 根因 | 修复与验证 |
|---|---|---|---|
| **P0 Critical** | 访问令牌与刷新令牌进入请求日志（读日志即可接管任意账户） | `app.module.ts` Pino 配置无 `redact`，自动请求日志序列化完整请求/响应头 | 新增 `common/log-redact.ts` 统一脱敏路径（`remove:true` 不可逆移除），覆盖 Authorization / Cookie / Set-Cookie / password / 私钥等。**验证**：4 个断言测试 + 真实服务实证——204 字符 access token 打 3 个受保护接口后，日志中出现 **0 次**（JWT 特征串 `eyJhbGciOi` 亦 0 次），而 `/summary` 请求日志仍正常记录（可观测性未受损） |
