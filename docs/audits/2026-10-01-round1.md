## Validated repairs

1. Credit minting on failed generation. Reservations increased reserved_credits without reducing balance; refund added balance. A100-credit failure changed1000→1100, and a denied2000-credit reservation's catch changed1100→3100. Introduced job-scoped transactional reservation states, once-only debit/refund/release and integer bounds. Denied jobs cannot release another job's reserve or mint funds. Real debit refunds once; unspent reserve release changes no balance.4 regression cases pass.
2. Gateway tenant collapse. Missing AIGC signing secret forwarded different tenants into shared default workspace; configured BFF accepted invalid signature by falling back to that workspace. Gateway now returns503 before forwarding; configured BFF requires valid signature; production missing configuration fails closed; invalid scope cannot become platform.5 unit regressions pass. Nonproduction unsigned local demo remains explicit.
3. Backup false success. POSIX pg_dump|gzip pipeline returned0 even when pg_dump exited42, promoted a31-byte partial backup and could run retention. Producer now completes first in private staging, compression is checked, promotion is atomic, and failed producer/sync retains old backups.2 fixture regressions pass; no real remote synchronization performed.
4. Callback SSRF address gaps. Blocked reserved IPv4, documentation networks, IPv6 transition/tunnel ranges and trailing-dot localhost. Existing DNS pinning remains; no private request was made. Callback guard suite11/11.
5. Frontend refresh correctness. A transient refresh outage logged the user out; a late refresh could revive logout/replace newer login. Track session generation, retain state for network/5xx failures, revoke only actual401/403 rejection, and reject stale refresh results.3 tests pass.
6. Factory provider failures now propagate as failed generation instead of charging and claiming completion.
