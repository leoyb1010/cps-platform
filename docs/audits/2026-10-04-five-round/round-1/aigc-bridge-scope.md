# AIGC real bridge audit, round 1 in progress

The UI sends educate/convert/retain. Studio formerly rejected convert/retain in both estimate and generation. Existing sell/explain/grow mappings also referenced nonexistent content template directions. The repaired shared intent catalog keeps all legacy values and the CPS values, selects actual supported template directions, and includes the original business goal in generated platform copy, cards and final video/storyboard actions before existing content policy processing.

A real disposable Nest-to-Studio HTTP run exercised three authenticated roles and all three UI intent values. Nine paths passed with estimate/actual charge equality, zero outstanding reservation, one debit, persisted job/input/output, and one CPS Asset for each customer-scoped result. Platform generation intentionally creates no customer Asset. All model/provider keys were empty and both server processes used the existing loopback-only network guard. Initial fixture expected a lowercase agent Asset ID; actual seed scope is A-2041 while Studio workspace normalization is agent-a-2041. The fixture was corrected against the actual source and DB row; no production ID behavior changed.

The UI now reads saved recent jobs independently of generation configuration, renders content as plain text, preserves current results through history failures, and offers retry. Results are typed: image-provider stubs expose their actual prompt and state that no image was generated; video results expose storyboard/preview and do not claim a final video. Owned-job PNG retrieval only accepts a numbered file from the saved owned job, verifies real export-root containment and PNG signature, and returns image/png with nosniff, restrictive CSP and private/no-store. HTML is never embedded under the CPS origin. The preexisting public Studio exports route was not expanded to expose custom export directories.

Current evidence: 17 Studio contract/owned-image tests; 93 frontend tests; actual local HTTP/DB readback. Browser-generated actual PNG bytes, download, reopened UI pixels, cross-role image readback and final CI remain open until the new isolated sidecar run completes. This does not establish live paid-provider correctness or final video production. No full round has yet been accepted.
